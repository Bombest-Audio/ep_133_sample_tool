<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app → Chrome Custom Tab | App passes a hardcoded TE URL to the system browser — no user-controlled URL |
| Custom Tab → TE updater | Chrome tab runs TE's site with full Chrome capabilities including WebUSB |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-999.3-06 | Tampering | URL passed to CustomTabsIntent | mitigate | URL is a compile-time string literal "https://teenage.engineering/apps/update"; no user or network input can change it |
| T-999.3-07 | Denial of Service | No browser installed | mitigate | catch(Exception) wraps launchUrl; snackbar message surfaced to user; app continues normally |
| T-999.3-08 | Information Disclosure | Chrome Custom Tab shares Chrome session with other TE pages | accept | User explicitly taps "Open updater"; no app credentials or private data sent to TE |
| T-999.3-SC | Tampering | No new package installs this wave | accept | androidx.browser already added in Plan 02 |
</threat_model>
