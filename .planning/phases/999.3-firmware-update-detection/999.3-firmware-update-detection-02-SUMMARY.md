## What Was Built

**FirmwareUpdateState** sealed class in `ui/device/DeviceScreen.kt`:
- `Idle` — initial, no check yet
- `Checking` — catalog call in flight
- `UpToDate` — device version >= latest
- `UpdateAvailable(current, latest)` — device version < latest; both versions available for banner
- `Unknown` — unparseable firmware string or catalog returned null

**DeviceViewModel additions:**
- `catalog: FirmwareCatalog = TeFirmwareCatalog()` constructor parameter (default keeps existing call sites unaffected)
- `private val _firmwareUpdate` + `val firmwareUpdate: StateFlow<FirmwareUpdateState>`
- `var onOpenFirmwareUpdater: (() -> Unit)?` + `fun openFirmwareUpdater()` (Wave 3 wires the Custom Tab)
- `private fun checkFirmwareUpdate()` — Checking → UpdateAvailable/UpToDate/Unknown with Log.w on failure
- `loadStats()` calls `checkFirmwareUpdate()` after stats query when `firmwareVersion != null`

**Manifest:** `<uses-permission android:name="android.permission.INTERNET" />` added; `usesCleartextTraffic="false"` unchanged.

**build.gradle.kts:** `implementation("androidx.browser:browser:1.8.0")` added.
