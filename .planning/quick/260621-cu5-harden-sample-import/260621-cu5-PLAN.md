# Quick Task 260621-cu5: Harden Android sample import

Robustness pass on the Android sample-import path so the hardware sound test is more likely
to pass first try and odd input files don't crash the app. All changes are pure-JVM and
fully unit-testable — no hardware required.

## Verified context

- `SampleImportManager.sanitizeName(rawName)` only rejects `/`, `\`, `..`, and control chars, then strips the extension and appends `.wav`. It does NOT enforce an ASCII-safe charset, cap length, or trim trailing whitespace/dots.
- `SysExProtocol.buildFilePutFrame` encodes the path with `path.toByteArray(Charsets.US_ASCII)` (SysExProtocol.kt:201/219/240). A non-ASCII basename (e.g. `café.wav`, emoji) is therefore lossily mangled into `?` bytes → the on-device `/sounds/<name>` path is corrupt and the file the sound test looks for won't be there.
- `Resampler.toRate(pcm, srcRate, dstRate, channels)` computes `pcm.size / channels` and `srcFrames * dstRate / srcRate` with no guard — `channels == 0` throws ArithmeticException (div-by-zero), `srcRate <= 0` misbehaves.
- Do NOT touch `MIDIRepository`, `SysExProtocol`, `AudioDecoder` (hardware-bound, can't unit test), or `WavEncoder`. Scope is `SampleImportManager.sanitizeName` + `Resampler.toRate` + tests.

## Task 1 — Harden sanitizeName (ASCII-safe, length-capped, trimmed)

**File:** `AndroidApp/app/src/main/java/com/ep133/sampletool/domain/midi/SampleImportManager.kt`

Rewrite `sanitizeName(rawName: String): String?` to produce a device-safe basename:

1. Take the basename: `rawName.substringAfterLast('/').substringAfterLast('\\')` then `substringBeforeLast('.')` to drop the extension (handle no-extension names — `substringBeforeLast('.')` returns the whole string when there's no dot, which is correct).
2. Replace every character NOT in the safe set `[A-Za-z0-9 _-]` with `_`. This makes the result pure ASCII so `US_ASCII` encoding in `buildFilePutFrame` is lossless. (This subsumes the old `/`, `\`, `..` rejection — those chars become `_`.)
3. Collapse runs of whitespace to single spaces, then `trim()` leading/trailing whitespace, and trim leading/trailing `.`/`_`/`-` so the device name is clean.
4. Cap the basename to a conservative length (e.g. `MAX_BASENAME_LEN = 32`) — EP-133 sample names are short; an overlong path risks device rejection. Truncate after sanitizing, then re-trim trailing `_`/`-`/space.
5. If the result is empty after all of this, return `null` (caller emits "Invalid sample name").
6. Return `"$base.wav"`.

Keep the method `public` (it's part of the tested contract). Update the KDoc to describe the new behavior (ASCII whitelist, length cap, trim) and keep the T-05-03-02 traversal-mitigation reference — note the whitelist now subsumes traversal rejection.

**Must not regress:** `sanitizeName("kick.wav") == "kick.wav"`, `"snare.wav" -> "snare.wav"`, `"hihat.wav" -> "hihat.wav"` (existing tests depend on these).

## Task 2 — Resampler input guards

**File:** `AndroidApp/app/src/main/java/com/ep133/sampletool/domain/audio/Resampler.kt`

At the top of `toRate`, before the fast-path:
- `require(channels >= 1) { "channels must be >= 1, was $channels" }`
- `require(srcRate > 0) { "srcRate must be > 0, was $srcRate" }`
- `require(dstRate > 0) { "dstRate must be > 0, was $dstRate" }`

Keep the existing fast-path and algorithm unchanged. Update the KDoc `@throws IllegalArgumentException` line.

## Task 3 — Tests

**File:** `AndroidApp/app/src/test/java/com/ep133/sampletool/` — add a new `SampleImportSanitizeTest.kt` (and extend `ResamplerTest.kt`).

`SampleImportSanitizeTest.kt` (construct a `SampleImportManager` with a no-op/disconnected `TestMIDIRepository`-style fake, or directly if `sanitizeName` doesn't need a connected device — it doesn't):
- `"kick.wav"`, `"snare.wav"`, `"hihat.wav"` pass through unchanged (regression lock).
- Non-ASCII name `"café.wav"` → result is pure ASCII (`all { it.code < 128 }`), ends in `.wav`, no `?`.
- Emoji / unicode-only basename → either a sanitized ASCII name or `null` (never a string containing non-ASCII).
- Traversal `"../../etc/passwd"` and `"a/b/c.wav"` → no `/`, `\`, or `..` in the result.
- Overlong name (e.g. 200 chars) → basename (excluding `.wav`) length `<= 32`.
- Trailing whitespace/dots `"  kick  .wav"` / `"kick...wav"` → trimmed, valid, ends in `.wav`.
- Empty / all-unsafe name (e.g. `""`, `"///"`, `"..."`) → `null`.

Extend `ResamplerTest.kt`:
- `toRate(shortArrayOf(1,2,3,4), 44100, 46875, channels = 0)` throws `IllegalArgumentException`.
- `toRate(shortArrayOf(1,2), srcRate = 0, ...)` throws `IllegalArgumentException`.
- Existing resample/no-op tests still pass.

Use `JAVA_HOME=$(/usr/libexec/java_home -v 17)` if needed; `local.properties` exists. Only the two production files + test files above may change.
